# 玩家系统开发记录

> 版本：v0.1（当前实现同步版）  
> 日期：2026-08-19  
> 文档性质：玩家角色、第一人称相机、输入和第一把剑的持续维护文档。当前实现以源码和已在编辑器中确认的资产为准。

## 1. 当前范围

玩家系统负责：

- 第一人称角色移动、视角和本地输入。
- 玩家运行时属性、伤害响应和死亡状态。
- 当前战斗切片所需的生命值、受伤红闪和死亡重开反馈。
- 第一把剑的输入、攻击状态、贴图表现、命中检测和反馈。
- 本地玩家的移动镜头反馈。

暂不包含：正式 GameMode、完整角色数据资产、技能/Perk、角色身体表现、正式 UI 视觉设计、复活流程和联机伤害权威化。

## 2. 类与组件

| 类/组件 | 职责 | 当前状态 |
|---|---|---|
| `AGobulinPlayerCharacter` | 角色本体、移动、相机、属性、输入路由和伤害响应 | 当前正式玩家类 |
| `AGobulinPlayerController` | 本地 Enhanced Input Mapping Context 和相机管理器 | 当前正式控制器 |
| `UGobulinCameraFeedbackComponent` | 移动上下晃动、横向移动侧倾 | 当前已接入 |
| `UBattleAttributeComponent` | 运行时属性容器和属性变化广播 | 当前已接入 |
| `UGobulinSwordCombatComponent` | 剑攻击状态、输入缓存、剑尖检测和伤害请求 | 当前第一把武器 |
| `UGobulinWeaponViewComponent` | 第一人称剑的变换支点和曲线驱动 | 当前已接入 |
| `UGobulinSwordFeedbackComponent` | 挥剑音效、命中音效、相机震动和 Hit Stop | 当前已接入 |
| `UGobulinSwordDefinition` | 剑的贴图、材质、曲线、时间和反馈参数 | `/Game/Art/Weapon/DA_Sword` |
| `UGobulinPlayerStatusWidget` | 原生 C++ 生命值、受伤红闪、死亡遮罩和重开入口 | 临时反馈层，待正式 UI 替换 |

玩家组件层级的核心关系：

```text
AGobulinPlayerCharacter
├─ FirstPersonCamera
│  └─ FirstPersonWeaponView       # 仅作变换支点，本身不渲染
│     └─ FirstPersonWeaponVisual  # Plane + 剑材质/贴图
│        └─ FirstPersonSwordTip   # 剑尖轨迹起点
├─ CameraFeedback
├─ BattleAttributes
├─ SwordCombat
└─ SwordFeedback
```

`PlayerStatusWidget` 不是 Actor Component，而是只为本地玩家创建并加入 Player Screen 的 `UUserWidget`。

`ADemoEnemy`、`AGobulinGameCharacter` 和 `AGobulinGamePlayerController` 不属于新的玩家功能入口，只保留作模板/过渡参考。

## 3. 玩家角色

### 3.1 基础设置

- `AGobulinPlayerCharacter` 直接继承 `ACharacter`，不依赖第一人称模板角色逻辑。
- 胶囊体是角色根节点；第一人称相机直接挂在胶囊体上，不挂骨骼、不依赖 AnimBP。
- 相机初始相对位置为 `Z = 64`，使用 Pawn Control Rotation，第一人称 FOV 当前为 `90`。
- 玩家本地不显示角色身体网格；远端角色表现由后续 2D 纸片方案补充。
- 角色启用复制移动，但当前主要验证单机流程。

### 3.2 移动与跳跃

当前基础参数：

| 参数 | 当前值/规则 |
|---|---|
| 基础移动速度 | `500 uu/s`，运行时来源为 `BattleTag_Movement_Speed` |
| 跳跃速度 | `420` |
| 空中控制 | `0.5` |
| 冲刺倍率 | `1.35` |
| 角色朝向 | 由控制器 Yaw 驱动，不朝移动方向旋转 |

剑攻击期间的规则由玩家角色属性和剑状态共同决定：

- 挥砍阶段移动速度倍率默认为 `0.85`。
- 收招阶段移动速度倍率默认为 `1.0`。
- 当前挥砍和收招阶段默认不允许跳跃、不允许冲刺。
- 剑攻击开始时默认取消冲刺。
- 当前没有禁止空中起手攻击的判断，因此空中可以开始新的剑攻击；如果后续需要限制，应在剑攻击入口明确增加规则。

### 3.3 属性与伤害

玩家在 `BeginPlay` 注册到 `UCombatantRegistrySubsystem`，获得 `FCombatantHandle`，结束时注销。

当前基础属性：

- `BattleTag_Health_Max = 100`
- `BattleTag_Health_Current = 100`
- `BattleTag_Movement_Speed = 500`

伤害流程为：

```text
攻击组件
  → FCombatDamageRequest
  → UCombatSubsystem
  → ICombatantEndpoint::ResolveCombatDamage
  → FCombatDamageResult / FCombatDamageResolvedEvent
```

玩家不会在武器表现组件中直接修改目标生命值。只有 `FCombatDamageResult` 确认实际应用伤害后，玩家才广播 `OnPlayerDamaged`；首次进入死亡状态时广播 `OnPlayerDied`。这两个动态委托同时携带已确认结果，后续 UI、音频和镜头表现不需要重新推断伤害是否生效。

玩家生命归零后会进入死亡状态，取消剑攻击、停止移动、禁用移动组件并关闭胶囊体碰撞，同时显示死亡界面并把本地输入切换到 UI。

## 4. 输入系统

`AGobulinPlayerController` 只为本地玩家添加 `DefaultMappingContexts`。正式玩家当前使用：

- `/Game/Input/IMC/IMC_Player`
- `/Game/Input/Actions/IA_Move`
- `/Game/Input/Actions/IA_Look`
- `/Game/Input/Actions/IA_Jump`
- `/Game/Input/Actions/IA_Sprint`
- `/Game/Input/Actions/IA_SwordAttack`

当前默认键位：

| Action | 默认输入 | 处理 |
|---|---|---|
| `IA_Move` | W/A/S/D | 相对控制器 Yaw 移动 |
| `IA_Look` | 鼠标 X/Y | 控制器 Yaw/Pitch |
| `IA_Jump` | Space | 开始/结束跳跃 |
| `IA_Sprint` | Left Shift | 开始/结束冲刺 |
| `IA_SwordAttack` | 鼠标左键 | 开始攻击并维护按住状态 |

`IMC_Default`、`IMC_MouseLook` 和 `IA_MouseLook` 属于模板兼容或旧输入资产，不作为正式玩家核心输入上下文。`IA_Interact`、`IA_PostBounty`、`IA_Pause` 已存在但尚未由正式玩家角色接线。

## 5. 相机反馈

`UGobulinCameraFeedbackComponent` 只在本地玩家启用 Tick，使用 Camera Component 的 Additive Offset，不覆盖玩家控制器的基础旋转。

- 移动时根据平面速度计算上下晃动权重。
- 上下晃动由频率、振幅、速度阈值和融合速度控制。
- 横向移动根据右方向速度施加 Roll，向左/向右方向相反。
- `bInvertStrafeRoll` 用于反转左右移动对应的侧倾方向，默认关闭以保持当前表现。
- 离地、停止移动或组件结束时清理 Additive Offset。

当前默认值包括：移动晃动频率 `1.8`、振幅 `2.5 uu`、侧倾角 `1°`。最终手感以 PIE 验收为准。

## 6. 临时玩家状态 UI

当前不使用 Commandlet 生成 WBP，也不要求额外蓝图资产。`AGobulinPlayerCharacter` 只为本地玩家创建 `UGobulinPlayerStatusWidget`，默认原生 Slate 内容包括：

- 左下角生命数值和生命条，颜色会随剩余比例由绿转橙、红。
- 每次已确认伤害触发一次短促全屏红闪，伤害越高峰值越明显。
- 玩家死亡后显示全屏遮罩、`你已倒下` 和 `重新开始` 按钮。
- 点击重开后调用本地 `PlayerController::RestartLevel`，重载当前关卡。

`PlayerStatusWidgetClass` 是正式 UI 的替换口。后续可以创建 `UGobulinPlayerStatusWidget` 的 WBP 子类并在 `BP_GobulinPlayerCharacter` 中替换：蓝图子类有自己的 WidgetTree 时保留设计器布局，并通过“玩家生命值已变化 / 玩家受到伤害 / 玩家死亡界面已显示或隐藏”事件接收数据；重开按钮调用 `RequestRestart` 即可。伤害规则和玩家死亡规则不需要迁移到蓝图。

本轮只提供能观察战斗闭环的反馈，不代表最终 HUD 美术、布局、动效、音效或复活设计。

## 7. 第一把剑

### 7.1 表现结构

剑采用纯贴图变换，不使用 Flipbook、手部模型或骨骼动画：

- `/Game/Art/Weapon/Sword`：剑贴图。
- `/Game/Art/Weapon/M_GobulinWeaponView`：无光照透明材质。
- `/Game/Art/Weapon/CV_Sword_AttackLocation`：攻击位置曲线。
- `/Game/Art/Weapon/CV_Sword_AttackRotation`：攻击旋转曲线。
- `/Game/Art/Weapon/DA_Sword`：统一配置资产。

`FirstPersonWeaponView` 是隐藏的变换支点，真正渲染的是子级 `FirstPersonWeaponVisual` Plane。子级 Plane 的位置、旋转和缩放由设计者在蓝图中手动调整，运行时不会按贴图宽高覆盖这些变换；剑柄对齐由 `FirstPersonSwordTip` 和子级相对变换共同完成。

### 7.2 攻击状态

剑状态为：

| 状态 | 说明 |
|---|---|
| `Idle` | 待机，可立即开始攻击 |
| `Attacking` | 推进攻击时间、应用曲线、检测剑尖轨迹 |
| `Recovery` | 返回待机后的短暂收招阶段 |

当前 `DA_Sword` 默认时间和窗口：

- 攻击时长：`0.45s`
- 收招时长：`0.10s`
- 命中窗口：归一化时间 `0.18 - 0.65`
- 输入缓存开启：归一化时间 `0.75`
- 挥剑音效节点：归一化时间 `0.20`
- 基础伤害：`20`

攻击流程：

1. 左键按下后，Idle 状态立即开始攻击。
2. 攻击期间推进曲线并执行命中窗口检测。
3. 输入缓存窗口开启后，新的攻击请求会缓存一次。
4. 进入 Recovery 后，若有缓存输入或仍按住左键，则自动开始下一次攻击。
5. 没有后续输入时回到 Idle。

### 7.3 曲线与编辑器预览

`UGobulinWeaponViewComponent::BeginAttackPose` 会记录当前待机相对变换，`SetAttackNormalizedTime` 根据归一化时间读取位置/旋转曲线并叠加到该基准姿态。攻击结束时恢复基准姿态。

编辑器中可以使用：

- `PreviewTime` 调整预览时间。
- `PreviewAttackPose` 预览当前曲线姿态。
- `ResetPreviewPose` 恢复待机姿态。
- `AGobulinSwordAnimationPreviewActor` 将 Sequencer 采样结果烘焙回两条 `CurveVector`。

后续调整攻击动作时，优先在 Sequencer 中制作和验收节奏，再烘焙到 `DA_Sword` 使用的曲线，避免逐个手调大量曲线关键帧。

### 7.4 剑尖命中

- `FirstPersonSwordTip` 是挂在剑视觉 Plane 下的 Arrow Component。
- 每帧记录剑尖上一帧和当前帧的位置，在命中窗口内做球体扫掠。
- 扫掠半径由 `DA_Sword.TipTraceRadius` 控制，当前默认为 `6 cm`。
- 同一次攻击通过 `DamagedTargetsThisAttack` 保证同一目标只受伤一次。
- 剑定义通过 `HitKnockbackSpeed / HitLaunchSpeed` 配置每次有效命中的轻微水平与垂直速度，并写入 `FCombatDamageRequest.Impulse`；目标端决定实际受击、硬直和致死倍率。
- 命中结果通过 `CombatSubsystem` 异步事件返回，只有实际应用伤害后才广播 `OnHitConfirmed`。
- `bDebugDrawTipTrace` 开启时绘制红色轨迹、黄色起点和绿色终点。

## 8. 攻击反馈

`UGobulinSwordFeedbackComponent` 只消费剑组件事件，不拥有攻击状态和命中规则：

- `OnSwingTriggered`：播放挥剑破风音效。
- `OnHitConfirmed`：在命中位置播放命中音效。
- 每次攻击首次有效命中：可触发 `CameraShakeBase`。
- 每次攻击首次有效命中：通过 `UGobulinHitStopSubsystem` 触发短暂 Hit Stop。
- 反馈只对本地玩家播放，避免远端角色重复播放本地第一人称效果。

## 9. 编辑器验收清单

修改玩家或剑系统后，优先检查：

- `BP_GobulinPlayerCharacter` 是否使用正确的玩家类和组件。
- `FirstPersonCamera` 是否挂在根胶囊体，视角和 FOV 是否正确。
- `FirstPersonWeaponVisual` 的 Plane、剑柄位置和缩放是否正确，贴图是否保持透明边缘和比例。
- `FirstPersonSwordTip` 是否位于剑尖，并随 Plane 正确移动。
- `BP_GobulinPlayerController` 是否添加 `IMC_Player`，五个 Action 是否正确赋值。
- `DA_Sword` 的材质、贴图、两条曲线、时间窗口、伤害、音效和 Camera Shake 是否正确。
- PIE 中移动、视角、跳跃、冲刺、左键攻击、输入缓存和按住连击是否符合规则。
- 攻击期间剑尖命中是否只对同一目标造成一次伤害。
- 命中时音效、相机震动和 Hit Stop 是否只在本地玩家触发。
- PIE 开始后左下角是否显示 `生命 100 / 100`，敌人接触伤害是否让数值和进度条同步下降。
- 每次实际扣血时是否出现短促红闪；敌人未真正造成伤害时不应误闪。
- 生命归零后角色是否停止，死亡遮罩和鼠标是否出现，点击 `重新开始` 是否重载当前关卡并恢复玩家。

## 10. 后续维护方向

- 将玩家基础移动、攻击限制和属性初始化逐步收敛到正式玩家数据配置，减少角色类中的默认数值。
- 明确空中攻击、冲刺取消和受击硬直等规则后，再扩展玩家状态层。
- 在玩法反馈验证完成后，由正式 UI/表现模块替换临时 HUD，并补充受伤方向、音效、镜头和正式死亡/复活流程。
- 在单机战斗闭环稳定后，再处理服务器权威伤害、预测和玩家远端表现。
- 新增武器时复用稳定的输入、反馈和命中协议，不恢复旧 W01/W03/W05 体系。
