## 1. 概述

### 1.1 一句话概念

永夜魔域，勇者如潮。你是魔王：在魔王城挂出悬赏引来冒险者大军，用魔剑、法术与魔王军守住自己的国土；每一次陨落都会在魔核中苏醒，变得更强。

### 1.2 游戏类型

- 主类型：第一人称射击（FPS）
- 叠加类型：类幸存者（Bullet Heaven / Horde Survivor）、增量养成（Incremental）、基地建设/塔防（Base Building / Tower Defense）
- 模式：单机 + 1-4 人合作联机（PvE，无 PvP）

### 1.3 平台与目标

| 项 | 目标 |
|---|---|
| 首发平台 | PC（Steam） |
| 引擎 | Unreal Engine 5.8 |
| 最低配置目标 | Win10 64 位、4 核 CPU、8 GB 内存、GTX 1050 级显卡 |
| 帧率目标 | 1080p / 60 FPS；4 人联机客户端 60 FPS |
| 单局时长 | 15-30 分钟（追加悬赏可加速） |

### 1.4 目标玩家

- 喜欢幸存者类割草快感的玩家；
- 喜欢 FPS 手感与武器养成的玩家；
- 喜欢「下班来一局变强一点」的增量游戏玩家；
- 有 1-4 人联机合作需求的轻社交玩家。

### 1.5 核心体验（一句话）

在魔力紧张、勇者铺天盖地的压力下，用越来越离谱的武器把一整片冒险者打退，然后带着战利品回魔王城继续经营。

## 2. 设计支柱

### 2.1 一秒成片的割草爽感

- 勇者潮以千为单位涌入，武器成长到中后期必须能「一枪一片」。
- 命中反馈三件套缺一不可：伤害数字/击杀播报、屏幕震动与音效、尸体/碎片/粒子表现。
- 敌潮有视觉密度上限管理，避免「满屏看不清」；通过分层颜色、剪影、体量区分威胁。

### 2.2 战斗手感即王道

- 这是 FPS：瞄准、后座、换弹、爆头、距离衰减都必须按射击游戏标准打磨。
- 弹药经济制造张力：魔力与箭矢初始稀缺，击杀补给形成「以战养战」的循环。
- 每把武器必须有手感差异（弹速、散布、后座模式、穿透、爆炸等），而不是数值换皮。

### 2.3 魔王是不死的

- 陨落不惩罚：本局获得的战利品全部结算。
- 转生设定：魔王陨落后在魔核中苏醒，记忆与力量沉淀——每一次战败都是下一次更强的开始。
- 用「下一局开局就比上一局强」的可感知曲线支撑增量核心。

### 2.4 魔王城是第二把武器

- 魔王殿是基地心脏：提供魔核能量、招募、升级与最后的防线。
- 炮塔、陷阱、城墙、魔王军构成自动化战斗力，玩家既是射手也是城主。
- 基地成长有可见性：每次回城都能看到新设施、新兵种、新住民。

### 2.5 群魔共守一城

- 联机共享同一座城、同一场悬赏；勇者潮规模与奖励按人数同步放大。
- 所有玩家都是魔王（不同名号），通过技能风格分工（近战/法术/巫术/召唤），任何名号都能独立战斗。
- 中途可加入/离开，进度不因队友掉线而毁灭。

## 3. 世界观与叙事

### 3.1 背景

人类王国与魔域交战百年。冒险者公会悬赏魔物、勇者渴望名声——每一年，都有成批的剑士、弓手、法师和圣职者涌入魔域。

旧魔王在百年圣战中陨落。年轻的魔王继承了城下的魔核，成为这片魔域的新君主。他没有征服人间的野心，只有一份责任：守住国土、守住城里的子民、守住魔王城。

### 3.2 玩家身份：魔王

- 气质：平静、克制、话少，但该出手时绝不犹豫；城民敬他，勇者畏他。
- 不做的事：不侵略、不毁灭世界、不搞宿命论。敌人不是「邪恶」，是立场；勇者不是「正义的化身」，只是一批批为了赏金和名望而来的人。
- 转生设定：魔王并非不死之身，但陨落后会在魔核中苏醒，记忆与力量随魔力一同沉淀。

### 3.3 叙事钩子

- 长线叙事：通过转生次数与头衔推进身份成长——新王 → 守望魔王 → 魔域之主 → 不灭魔王 → 深渊之王。
- 短叙事钩子：每次结算时，城内住民对当夜事件做出简短回应；转生深度解锁会揭开魔核与旧魔王记忆的碎片化叙事。
- 主线不宏大：没有「拯救世界」，只有「这是我家，别来拆」。

### 3.4 城民/NPC（5 位）

| NPC | 功能 | 性格/作用 |
|---|---|---|
| 魔匠·熔金 | 武器锻造/图纸 | 毒舌但手艺极好，负责武器 Tier 与图纸研究 |
| 附魔师·魅影 | 武器 Mod 与附魔 | 神秘系，负责附魔插槽与 Mod 合成 |
| 魔池总管·骨爵 | 魔王军训练 | 老将，负责魔池、兵种与战术升级 |
| 黑市商人·鸦 | 材料兑换与随机货品 | 灰色交易，提供限时折扣与图纸碎片 |
| 炼金师·毒涎 | 药剂与 Buff、复活 | 冷漠系，负责局内消耗品与复活次数 |

## 4. 核心循环

### 4.1 局内循环（单场悬赏）

```
入夜准备（选武器/布置临时防御/选择悬赏等级）
  → 发布悬赏（选择风险等级）
  → 勇者潮涌入（悬赏等级上升）
  → 战斗：击杀、拾取金币/魔核、补给弹药
  → 升级：魔力/武技/Perk/武器 Tier 三选一
  → 压力管理：修墙、修炮塔、追加悬赏加码
  → 传说勇者事件
  → 结算：战利品转永久资源
```

### 4.2 局外循环（魔王城）

```
结算 → 回城
  → 锻造/升级武器（消耗金币+魔核）
  → 升级设施（锻造台、附魔台、魔池、金库）
  → 训练魔王军/升级防御件
  → 提升转生头衔（解锁新内容）
  → 选择转生深度（NG+ 式）
  → 入夜准备
```

### 4.3 联机循环

同一场悬赏内所有玩家共享：悬赏等级、狂潮状态、城防耐久、共享建造预算、夜间阶段。个人独立：局内等级、Perk、武器、个人战利品。结算时共享城防收益，个人战利品归个人。

## 5. 玩家与战斗

### 5.1 移动与操作

- 标准 FPS 移动：WASD、跳跃、下蹲、冲刺（带体力条）、交互。
- 武器切换：两把主武器 + 一把近战（初始魔剑），支持快捷切换。
- 瞄准：腰射与瞄准镜（ADS），不同武器 ADS 收益不同。
- 输入：Enhanced Input；支持键鼠与手柄（手柄为次要目标）。
- 无障碍：可调灵敏度、震动强度、准星尺寸、辅助瞄准（联机 PvE 可用）。

### 5.2 武器系统

#### 武器原型（10 种，魔女系 4 种）

| 武器 | 风格 | 手感关键词 |
|---|---|---|
| 魔剑「断岳」（初始近战） | 通用近战 | 重击、击退、斩杀回魔力 |
| 月镰「蚀月」 | 魔女近战 | 弧形挥砍、命中多个、回魔更高 |
| 魔弓「噬星」 | 精准 | 蓄力穿透、可爆头、距离衰减平滑 |
| 连弩「蜂刺」 | 速射 | 高射速、低散布、弹药轻 |
| 法杖「渊火」 | 法术 | 火球连发、蓄力变火雨、AOE 清场 |
| 魔铳「噬魂」 | 重火力 | 单发高伤、强击退、距离衰减明显 |
| 药锅炸弹「万灵汤」 | 魔女投掷 | 抛物线、毒/火/霜三汤切换、区域控场 |
| 诅咒人偶「代罪者」 | 魔女追踪 | 标记目标、人偶追踪爆炸、可连锁 |
| 塔罗飞牌「命运」 | 魔女弹幕 | 快速连发、可回旋、暴击率高 |
| 灭勇炮「魔王终响」 | 终局重武器 | 缓慢装填、单发毁灭性、打 BOSS 用 |

#### 武器成长

- 每把武器 5 个 Tier；Tier 提升改变数值曲线并解锁 1 个「形态变化」（如药锅从投掷变毒雨、人偶从单目标变连锁爆炸）。
- 每把武器 3 个附魔插槽：由附魔师解锁；Mod 来自局内掉落与图纸锻造。
- 武器图纸（Blueprint）是解锁新武器的关键：由精英、BOSS、转生深度掉落。

#### 弹药经济（核心张力）

- 初始魔力与箭矢稀缺，保证「打空」是常态而非例外。
- 补给规则（示例）：
  - 近战斩杀 → 回魔力；
  - 弓手/狮鹫骑士击杀 → 掉箭矢；
  - 精英击杀 → 掉魔铳/药锅补给；
  - 时间充能 → 法杖魔力恢复；
  - 压力波（无弹药时）→ 使用魔铳应急或追加悬赏强行换资源。
- 弹药稀缺让武器切换、近战补刀和悬赏节奏形成策略三角。

### 5.3 局内成长（Perk 与属性）

- 击杀获得经验 → 升级 → 从 3 个随机选项中选择 1 个（Perk 或属性或武器强化）。
- Perk 五系：
  - 兵刃系：换弹速度、后座控制、暴击、穿透、弹匣；
  - 体魄系：血量、护甲、冲刺次数、吸血；
  - 掠夺系：战利品倍率、经验倍率、掉落率；
  - 城防系：炮塔伤害、魔王军强化、修复速度；
  - 悬赏系：魔核充能加速、狂潮持续时间、悬赏收益。
- 主动技能（局内习得）：如「魔王威压」「魔核炸弹」「召唤骨龙冲锋」。
- 构筑思路：鼓励「1 个主武器特化 + 1 个体魄底子 + 1 个掠夺/城防插件」，后期允许超模组合（割草爽感的来源）。

### 5.4 悬赏系统（核心辨识点）

#### 机制

- 悬赏充能（Bounty Charge）：随时间与击杀回复，最多 3 格。
- 发布悬赏一次：悬赏等级 +1、勇者潮生成速率与血量上升、战利品倍率 +X%、魔王城获得 1 份「魔核能量」（用于修复、炮塔过载、魔王军增援）。
- 追加悬赏（在狂潮窗口内再次发布）：进入「狂潮」状态——勇者数量翻倍、战利品 ×2、精英提前出现；狂潮持续 90 秒或直至能量耗尽。
- 传说勇者事件：悬赏总量到达阈值后触发 BOSS 战；也可以主动在狂潮中追加悬赏提前召唤传说勇者换额外奖励。

#### 设计意图

悬赏同时是「加难度」和「加收益」的开关，且提供魔核能量——玩家必须决策：保守守城（低风险低收益）还是连续追加悬赏爆富（高风险高收益）。这构成局内每 1-2 分钟一次的微型决策。

### 5.5 勇者潮敌人设计

#### 敌群组织

- 基础单位（Chaff）：占比 70%+，成群出现，负责「割草密度」。
- 威胁单位（Threat）：中高价值，要求玩家改变射击目标。
- 精英（Elite）：带光环或特殊机制，掉图纸/大量资源。
- BOSS（3 个）：每场传说勇者事件出现，机制明确。

#### 敌人表（首发 14 种）

| 敌人 | 类别 | 行为 | 玩家应对 |
|---|---|---|---|
| 见习剑士 | Chaff | 持剑直线冲锋 | 扫射/近战 |
| 流浪弓手 | Chaff | 远处放箭 | 优先清理远程 |
| 盗贼 | Threat | 高速绕后 | 霰弹/药锅 |
| 见习法师 | Threat | 火球抛射 | 机动躲避、集火 |
| 圣殿牧师 | Threat | 给周围怪加血/加护 | 优先集火 |
| 盾卫骑士 | Tank | 举盾推进 | 绕后/爆炸/蓄力 |
| 狂战士 | Threat | 加速冲锋、近身爆炸输出 | 保持距离 |
| 狮鹫骑士 | Threat | 飞行、俯冲攻击 | 魔弓/飞牌点射 |
| 猎魔人 | Threat | 十字弩点射、标记玩家 | 掩体/优先击杀 |
| 圣武士 | Elite | 光环：附近勇者减伤/加速 | 优先集火 |
| 魔法骑士 | Elite | 剑术+法术二段攻击 | 打断施法、拉开距离 |
| 勇者小队 | BOSS | 三职业协同、阶段切换 | 清杂 + 逐一点名 |
| 圣骑士团长 | BOSS | 高机动近战、圣光爆发 | 控制节奏、换武器 |
| 传说勇者 | 终局 BOSS | 全机制 + 多阶段 | 武器成型验证 |

### 5.6 难度曲线

- 悬赏等级决定当夜怪物基础强度；转生深度（1-10）提供跨局长期难度。
- 每局由「玩家选择的悬赏节奏」决定实际压力，系统只提供基线。
- 设计原则：前 5 分钟任何构筑都能玩；第 10-15 分钟构筑差异拉开；20 分钟后允许超模（割草高潮）。

## 6. 基地建设（魔王城）

### 6.1 基地形态

- 魔王殿：核心建筑，不可移动；被攻破则当局失败。
- 地块系统：城内/城墙周边为网格地块（初始 4×4，可扩建到 6×6）。
- 双轨建造：
  - **局外永久设施**：锻造台、附魔台、魔池、金库等，决定能力上限与科技树；
  - **局内临时防御**：用当局资源建造墙/炮塔/陷阱，悬赏结束后重置但保留蓝图配方。

### 6.2 设施清单（首发 10 个）

| 设施 | 类别 | 功能 |
|---|---|---|
| 魔王殿（核心） | 核心 | 悬赏发布、魔核能量分配、城防生命 |
| 魔匠锻造台 | 生产 | 武器 Tier 升级与图纸研究 |
| 附魔台 | 生产 | Mod 合成/附魔 |
| 魔核熔炉 | 生产 | 资源转换（金币↔冥银） |
| 魔池 | 军事 | 魔王军训练、编队、战术 |
| 炮塔平台 | 军事 | 解锁/升级炮塔蓝图 |
| 城墙/闸门 | 防御 | 城防耐久、阻挡路线 |
| 陷阱工坊 | 防御 | 地刺/毒雾/雷区 |
| 盟友房间 | 功能 | 黑市商人/炼金师等入驻 |
| 金库 | 经济 | 共享资源上限与每日利息 |

### 6.3 魔王军

- 魔池解锁三种兵种：哥布林战士（近战）、魔蝠弓手（远程）、石像魔炮手（范围）。
- 上限由魔池等级决定；悬赏中自动驻守固定防线，可被玩家指挥（简单标记目标区域）。
- 士兵阵亡不永久损失，但当晚无法补充超过上限；魔池升级提供更强兵种形态（骨龙为终局形态）。

### 6.4 联机下的魔王城

- 城防世界状态以房主存档为准；所有玩家共享建造预算与设施等级。
- 建造权限：默认所有玩家可建可拆（共享预算）；房主可开启「仅房主建造」。
- 临时防御预算按玩家数缩放：4 人时预算 ×2.5 左右，避免人多反而挤。

## 7. 增量成长（Meta）

### 7.1 货币与资源

| 资源 | 获取 | 用途 |
|---|---|---|
| 金币（Gold） | 局内击杀/悬赏加成 | 局内购买、临时防御、部分局外升级 |
| 魔核（Demon Core） | 局内精英/BOSS/结算 | 锻造、设施升级 |
| 冥银（Nether Silver） | 结算转换（上限保护） | 永久科技树 |
| 图纸碎片（Shard） | 精英/BOSS/任务 | 解锁武器图纸 |

### 7.2 转生与头衔（Ranks）

- 通过累计击杀、完成悬赏次数、总冥银获取推进。
- 头衔解锁：新武器、新敌人类型、新转生深度、新设施、装饰。
- 头衔序列：新王 → 守望魔王 → 魔域之主 → 不灭魔王 → 深渊之王。

### 7.3 转生深度（Rebirth Depth，NG+ 式）

- 每完成一次「传说勇者讨伐」（通关任意 BOSS）解锁下一转生深度。
- 深度效果：勇者血量/数量/战利品同步上升，并解锁新敌人与 BOSS 变体。
- 目的：给满级玩家持续目标，且避免「数值无限膨胀后没有对手」。

### 7.4 数值原则

- 曲线用「对数增长 + 里程碑跳变」：长期增长平滑，关键节点（Tier 变化、新武器）提供跳变爽点。
- 所有永久升级必须有可感知效果（数值变化同时在魔王城里可视化，如炮塔变大、熔炉更亮）。
- 防止指数爆炸：每个维度有上限，解锁上限本身是内容（如冥银上限扩展）。

## 8. 联机模式设计（摘要）

详细方案见 [future/04-联机方案.md](./future/04-联机方案.md)。此处只列玩家视角规则：

- 1-4 人；房主建房（难度/转生深度/人数上限），好友/邀请码加入。
- 所有玩家都是魔王，各有名号（剑渊魔王/焰狱魔王/永夜魔女/冥渊魔王），共享同一座城与同一场悬赏；勇者潮规模按人数缩放。
- 共享：悬赏等级、狂潮、城防耐久、建造预算、夜间阶段、胜利/失败。
- 独立：个人等级、Perk、武器、个人战利品、复活次数。
- 玩家倒下：可被队友用炼金师药剂或「魔王威压」拉人；全灭才失败。
- 中途加入：仅限入夜准备阶段（MVP）；掉线 60 秒内可重连。
- 单机与联机共享同一套成长档案；单人可随时把档案带进联机房间。

## 9. UI/UX 原则

- HUD 优先级：准星/魔力 > 敌情预警 > 悬赏槽 > 城防耐久 > 资源。
- 受伤/击杀反馈用屏幕边缘效果，不遮挡视野。
- 建造模式：清晰网格预览、预算提示、冲突高亮。
- 菜单深度 ≤ 3 层；结算界面给出「本局收获」与「可购买项」对比，明确下一步目标。
- 支持简中/繁中/英文；数字用大字体，避免 UI 缩放模糊。

## 10. 美术与音频方向

### 10.1 美术

- 风格：**3D 低模场景 + 全 2D 纸片角色**（勇者潮、NPC、BOSS 全部 2D），暗黑童话手绘质感。
- 色调：魔王城暖色（熔炉/篝火/魔核光） vs 战场冷色（夜色/月光/圣光），对比明确。
- 角色可读性：2D 角色统一高对比描边与剪影；Chaff 同色系、Threat 高饱和、精英发光、BOSS 体型+音效识别。
- 角色分层与朝向：杂兵 1 方向面向相机；玩家/队友/NPC 用 8 方向帧（4 方向绘制 + 水平镜像），按移动/瞄准方向切换；玩家阵营统一描边 + 名牌。
- 玩家手部武器：相机挂载的 2D FPS 武器贴图层（Flipbook + 程序化摆动），与 2D 角色风格统一；联机中仅本地可见。
- 特效：Niagara 粒子，保证低配可用（Pool 化、LOD 降级）。

### 10.2 音频

- 武器音必须逐把制作（魔力迸发、弓弦、药锅沸腾、飞牌破空）。
- 悬赏是叙事与机制核心：发布悬赏时「悬赏令张贴 + 战鼓由远及近」的音效要既庄严又危险。
- 勇者潮音量分层：密度越高越低沉，给玩家「越来越近」的潜意识压力。
- 联机语音：Steam 语音或第三方，默认关闭，需手动开启。

## 13. 明确不做（范围控制）

- 不做 PvP/排名赛。
- 不做开放世界；魔王城 + 悬赏战场是固定场景结构。
- 不做角色创建；玩家是固定身份的魔王（通过名号/武器/Mod 表达差异）。
- 不做建造自由度上的全自由搭建；采用地块 + 蓝图配方制，避免建造系统吃掉开发预算。
- 不做坐骑/载具（狮鹫骑士是敌人，不是玩家玩法）。
- 不做侵略/征服玩法：魔王守家，不进攻人类王国。
