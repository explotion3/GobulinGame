## 2. 官方卖点拆解

| 卖点 | 机制本质 | 对我们的启发 |
|---|---|---|
| 千人同屏的怪物潮 | 大规模渲染与模拟技术；"thousands of units on screen" | 必须自研/选用 Mass Entity 级方案，不能靠传统 AIController |
| 敲钟主动召唤怪群 | 玩家掌控节奏的风险/收益开关 | 节奏由玩家主导，而非纯倒计时刷怪；「越贪越赚」构成核心张力 |
| 增量式成长 | Megabonk/Clicker 式数值增长；"nothing is lost on death" | 死亡无惩罚、每局沉淀永久成长 |
| 局内等级与被动 Perk | 幸存者式局内三选一/属性成长 | 局内构筑 + 局外成长双循环 |
| 武器解锁与升级 | 武器库从一把简单枪械到屠龙级 | 武器是核心内容载体，需要有清晰的天梯与改造深度 |
| 重建堡垒 | 修复设施、建造防御、训练骷髅军队 | 基地不是摆设，是第二个成长系统和战斗资源 |
| 招募古怪盟友 | NPC 提供功能与性格化内容 | 用少量高辨识度 NPC 支撑基地叙事与功能解锁 |

## 3. 机制细节（含 Demo 反馈）

### 3.1 核心循环

夜晚开始 → 怪物持续涌入 → 玩家敲钟主动拉更多怪 → 击杀获得经验/金币/资源 → 局内升级、解锁武器 → 压力不断升高 → 最终 BOSS → 胜利或死亡 → 结算进入永久成长 → 下一夜更难也更爽。

### 3.2 钟声系统

- 钟声是「风险/收益开关」：敲钟会一次性引来更多怪物，但资源产出也更高。
- 可以连续敲钟：Demo 中连敲多次会让敌人数翻倍，用于快速刷钱。
- 节奏由玩家决定，而非系统强制：这是它与传统波次塔防最大的不同。

### 3.3 武器与弹药经济

Demo 反馈要点：

- 初始弹药稀缺，需要「以战养战」：近战刀杀给手枪弹药，射杀空中怪给步枪弹药。
- 步枪等强武器弹药稀有，通常留到 BOSS 阶段使用。
- 魔法/消耗手段用来顶住高压波次。
- 玩家评价「刀和枪械的手感做得非常好」——证明该作把 FPS 手感当成生死线。

### 3.4 局内成长

- 经验升级 → 属性 + 被动 Perk。
- 武器有等级/阶位（tier），解锁新武器并升级到更高阶段后杀伤力质变。

### 3.5 局外增量成长

- 金币、经验、资源从战斗中获取。
- 死亡不丢失任何东西（"nothing is lost on death"）。
- 军衔/头衔推进（Apprentice Bell Ringer → Master Dragon Hunter），同时是成长进度与叙事身份。

### 3.6 基地建设与塔防

- 训练骷髅大军协防。
- 修复基地设备、建立防御系统。
- 招募各种盟友，提供成长与功能。

## 5. 借鉴与差异化

### 我们保留的方向

- FPS 手感为核心：手动瞄准、命中反馈、弹药经济。
- 主动风险开关（我们采用发布悬赏）：节奏由玩家掌控。
- 千人敌潮 + 幸存者式局内构筑。
- 死亡无惩罚的增量成长。
- 基地建设 + 防御 + 军队。

### 我们的差异化（避免同质化）

| 维度 | Guns 'n Goblins | 我们的设计 |
|---|---|---|
| 阵营/视角 | 人类守钟人 | 魔王阵营：玩家是魔王，发布悬赏引勇者潮，反向守城 |
| 美术 | 像素风 2D/伪 3D | 3D 低模场景 + 全 2D 纸片角色（勇者潮与 BOSS 全 2D），暗黑童话手绘风 |
| 引潮机制 | 敲钟召唤怪群 | 发布悬赏：悬赏越高，勇者潮越强、战利品越多、魔核充能越足 |
| 基地 | 修复与升级 | 魔王城：局外永久设施（魔池/附魔台/炼金室）+ 局内临时防御双轨；联机共享建造预算 |
| 联机 | 未公布联机 | 1-4 人合作是核心卖点；全员魔王名号（剑渊/焰狱/永夜魔女/冥渊） |
| 成长 | 单货币 + 武器升级 | 三资源（金币/魔核/冥银）+ 图纸锻造 + 转生头衔 + 转生深度（NG+ 式） |
| 职业 | 无明确职业 | 魔王名号区分技能风格（近战/法术/巫术/召唤），单机可切换 |

## 6. 对规划的影响（结论）

1. 战斗手感必须最先验证：M1 垂直切片就是「枪械手感 + 千人敌潮」。
2. 海量敌人是技术主线，必须在 M1 就把 Mass/ISM 方案跑通，不能后置。
3. 悬赏机制是玩法辨识点，值得围绕它做一套经济系统（风险、收益、能源）。
4. 增量成长需要严格的数值设计，否则后期会失去目标感；用转生头衔/转生深度做长线里程碑。
5. 联机不是「单机加个功能」，敌潮同步方案必须与技术架构同时定型。
