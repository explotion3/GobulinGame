# 基础内容设计（不含剧情设定）

> 版本：v0.1（基础框架稿）  
> 日期：2026-08-09  
> 文档性质：长期内容分类与 ID 规划。当前 M1 只落地第一把剑和正式敌人基础框架，W01-W10、S01-S05 等表格是后续内容储备。  
> 原则：**本阶段只定义类型、作用与机制参数；所有剧情名称（武器名、称号名、NPC 名等）后置填充，不参与设计。**

## 1. 命名与 ID 规范

为避免剧情命名干扰机制设计，基础内容统一使用功能 ID：

| 内容 | ID 规则 | 示例 |
|---|---|---|
| 武器 | `W01`-`W10` | W01 = 近战·清杂 |
| 称号 | `S01`-`S05` | S01 = 近战·重装 |
| 敌人 | `E01`-`E13` | E01 = 基础近战·炮灰 |
| 设施 | `B01`-`B10` | B01 = 核心建筑 |
| 魔王军兵种 | `M01`-`M03` | M01 = 近战步兵 |
| Perk | `P01`-`P40` | P01 = 换弹速度 |

剧情命名（如「断岳」「永夜魔女」）在机制定稿后由设定文档统一填充。

### 2.4 武器通用框架（独立于具体武器）

- 等级：Tier 1-5，每级改变数值曲线，Tier 5 解锁形态变化。
- 附魔：3 个插槽，Mod 分「伤害/射速/弹药/穿透/暴击/元素」六类。
- 图纸：武器解锁依赖图纸（精英/BOSS/转生深度掉落）。
- 弹药补给规则按弹药类型挂到武器数据，不写死在角色代码。

### 3.4 称号通用框架

- 称号不是独立职业代码，而是「武器偏好 + 主动技 + 被动倾向」的预设组合。
- 主动技与被动全部走同一套 Perk/技能数据，称号只是开局默认配置。
- 单机可自由切换称号；联机每名玩家选一个（允许重复）。
- 工程型（S05）已确认保留为第 5 个称号（2026-08-09 决策）。

## 8. 悬赏与成长框架（机制部分）

### 8.1 悬赏机制

- 悬赏等级：1-5，决定当局基础难度与收益。
- 追加悬赏：狂潮窗口内再次发布，勇者翻倍、战利品 ×2、精英提前。
- 魔核充能：发布悬赏为城防系统供能（修复/炮塔过载/军队增援）。

### 8.2 货币

| 货币 | 作用域 | 用途 |
|---|---|---|
| 金币 | 局内 | 临时购买/建造 |
| 魔核 | 局内外 | 锻造/设施 |
| 冥银 | 永久 | 科技树 |
| 图纸碎片 | 永久 | 解锁武器 |

### 8.3 转生与头衔（功能层）

- 头衔 = 解锁位（新武器/敌人/深度/设施），剧情命名后置。
- 转生深度：1-10，NG+ 式难度。
