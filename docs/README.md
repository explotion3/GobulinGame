# Gobulin 项目规划文档

> 工作名：**《魔王城》**（The Demon Lord's Keep，暂定）  
> 引擎：Unreal Engine 5.8（C++ 为主 + 蓝图做内容）  
> 最后更新：2026-08-09  
> 状态：**规划阶段，未开始动工**

## 一句话描述

一款「FPS × 类幸存者 × 增量养成 × 基地建设 × 联机合作」的魔王主题游戏：玩家扮演魔王，在魔王城发布悬赏引来成千上万的勇者潮，用魔剑、法术与魔王军守住国土；每一次陨落都会在魔核中苏醒、变得更强。

## 设计支柱

1. **一秒成片的割草爽感**——千人同屏、武器成型的视觉与操作反馈是第一体验。
2. **枪械手感即王道**——这是 FPS，不是套了 FPS 皮的幸存者；射击、换弹、后座、命中反馈必须达到射击游戏水准。
3. **每次死亡都有意义**——罗格轻量、增量核心：死亡无惩罚，每一局都沉淀为永久成长。
4. **魔王城是第二把武器**——魔王殿、炮塔、魔王军、城民共同构成可成长、可协作的防御体系。
5. **群魔共守一城**——1-4 人合作，全员都是魔王（不同名号），共享同一座城与同一场悬赏。

## 关键决策速览

| 维度 | 决策 |
|---|---|
| 玩法类型 | FPS × 类幸存者 × 增量养成 × 基地建设 × 合作联机 |
| 题材/身份 | 魔王阵营：玩家是魔王，发布悬赏引勇者潮 |
| 联机规模 | 1-4 人 PvE 合作，无 PvP；全员魔王名号 |
| 联机拓扑 | MVP 用 Listen Server（房主同玩），发布前再评估专用服务器 |
| 权威模型 | 服务器权威 + 客户端预测；海量勇者潮用「批次快照 + 客户端同构模拟」混合同步 |
| 死亡惩罚 | 死亡=转生，无惩罚；局内收益全部结算为永久成长 |
| 局内时长 | 15-30 分钟/局，可追加悬赏加速 |
| 美术 | 3D 低模场景 + 全 2D 纸片角色（含 BOSS） |
| 技术路线 | UE 5.8 + C++；Mass Entity 做千人敌群；数据驱动用 DataAsset/DataTable/GameplayTags |
| 开发顺序 | 单机垂直切片 → 系统完整 → 基地 → 联机 → 内容打磨 → 发布 |
