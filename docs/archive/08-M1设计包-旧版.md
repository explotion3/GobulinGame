# M1 设计包（垂直切片数值与配置）

> 版本：v0.1（原型数值稿）  
> 日期：2026-08-09  
> 范围：仅 M1 垂直切片所需内容；所有数值为原型值，首轮试玩后修订。  
> 原则：只定义机制与数值，不含剧情命名。

## 1. 输入映射

### 1.1 Action 清单

| 操作 | Action 名 | 类型 | 默认键 | 备注 |
|---|---|---|---|---|
| 移动 | IA_Move | Axis2D | WASD | 走 |
| 视角 | IA_Look | Axis2D | 鼠标 | 灵敏度可调 |
| 跳跃 | IA_Jump | Bool | Space |  |
| 冲刺 | IA_Sprint | Bool | Shift | 消耗体力 |
| 开火 | IA_Fire | Bool | 左键 | 按住连发/蓄力 |
| 瞄准 | IA_Aim | Bool | 右键 | ADS |
| 换弹 | IA_Reload | Bool | R | 近战武器无弹匣 |
| 近战 | IA_Melee | Bool | V | 使用近战武器 |
| 切换武器 | IA_SwitchWeapon | Axis | 1/2 或滚轮 | 主/副切换 |
| 交互 | IA_Interact | Bool | E | 修复/拾取/对话 |
| 发布悬赏 | IA_PostBounty | Bool | T | 发布/追加悬赏 |
| 暂停 | IA_Pause | Bool | Esc | 打开菜单 |

### 1.2 输入映射上下文（IMC）

| IMC | 优先级 | 内容 | 生效场景 |
|---|---|---|---|
| IMC_Default | 0 | 上述全部 Action | 游戏内 |
| IMC_UI | 10 | 暂停/菜单/UI 导航 | 菜单与 UI（M2 起） |

切换规则：进入 UI 时只启用 IMC_UI 并设置 UI 输入模式；回到游戏时切回 IMC_Default。M1 只实现 IMC_Default。

## 5. 悬赏数值（M1：等级 1-3）

### 5.1 基础波次

- 节奏：每 5 秒一批，每批 5 只；构成 E01 60% / E02 25% / E08 15%。
- 生成位置：地图边缘固定入口（2 个）。

### 5.2 悬赏等级

| 等级 | 生成倍率 | 血量倍率 | 掉落倍率 | 魔核充能 | 备注 |
|---|---:|---:|---:|---:|---|
| 1 | ×1.0 | ×1.0 | ×1.0 | +1 | 基础 |
| 2 | ×1.5 | ×1.15 | ×1.3 | +2 |  |
| 3 | ×2.0 | ×1.3 | ×1.6 | +3 | 精英出现概率 10% |

### 5.3 追加悬赏（狂潮）

| 项 | 规则 |
|---|---|
| 持续时间 | 90s（追加后重置） |
| 效果 | 数量 ×2、掉落 ×2 |

| 悬赏充能 | 基础 60s 回 1 格；精英击杀 +1 格；上限 3 格 |

## 7. 数值原则

- 以上全部为原型值，首轮试玩后统一修订，不单独调平衡。
- 设计目标：W01 清杂回魔 → W05 消耗魔力清场 → W03 点名精英，形成 M1 的最小资源循环。
